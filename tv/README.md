## How to run the player

You must run it through a local web server because browsers generally block fetching JSON files directly through `file://`.

Using VS Code:

2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select Open with Live Server.

Alternatively, with Python installed:

bash

```bash
python3 -m http.server 8000
```

Open:

text

```text
http://localhost:8000
```
